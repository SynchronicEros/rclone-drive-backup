rclone 個人備份工具｜首頁與隱私權政策

本頁說明 Google Cloud 專案「rclone-eros」之 OAuth 應用程式「rclone」。

用途

本應用程式為開源工具 rclone 之個人設定，僅供擁有者本人在自己的電腦上備份與查核自己的 Google 雲端硬碟檔案，不對外提供服務，亦不開放他人使用。

存取之資料

經擁有者本人授權後，rclone 存取擁有者自己 Google 雲端硬碟中之檔案（列出、上傳、下載、比對雜湊值）。

資料之使用、儲存與分享

  • 資料只在擁有者本人之電腦與其 Google 雲端硬碟之間傳輸。
  • 不蒐集、不分析、不出售，亦不與任何第三方分享任何使用者資料。
  • 授權權杖只儲存在擁有者本人之電腦。

撤銷授權

可隨時於 Google 帳戶之「第三方應用程式與服務」移除本應用程式之存取權。

聯絡

請經 GitHub 與擁有者聯絡：github.com/SynchronicEros

English summary

This OAuth app ("rclone", project "rclone-eros") is a personal configuration of the open-source tool rclone, used solely by its owner to back up and verify the owner's own Google Drive files on the owner's own computer. No user data is collected, sold, or shared with any third party. Tokens are stored only on the owner's computer. Access can be revoked at any time in Google Account settings.
